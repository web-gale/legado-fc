# Manual del usuario

1. Pulsa **Crear nueva carrera**, escribe nombre y elige nacionalidad, posición, personalidad y dificultad.
2. Comenzarás con 14 años como **agente libre**. En **Mercado**, revisa y acepta la primera oferta de un club del país elegido.
3. En **Temporada**, selecciona entrenamiento e intensidad. La simulación se habilita después de firmar el primer contrato.
4. Revisa el resumen, lesiones, noticias, atributos y valor. En **Mercado**, renueva o acepta nuevas ofertas.
5. Consulta **Estadísticas** para el historial completo. Exporta JSON como copia e impórtalo cuando quieras.
6. Desde los 32 puedes retirarte voluntariamente; entre 35 y 42 el estado físico puede cerrar la carrera. **Legado** mostrará el informe final.

El cian indica progreso/acción; el naranja, riesgo o cambio. El engranaje alterna claro/oscuro. El guardado ocurre tras crear, avanzar, renovar o fichar. Como la partida vive en el navegador, exporta una copia antes de borrar datos del sitio o cambiar de dispositivo.
